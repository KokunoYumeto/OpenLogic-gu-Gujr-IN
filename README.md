# ઓપન લોજિક — ગુજરાતી (gu-Gujr-IN)

Gujarati scholarly translation of the Open Logic Project. The full 722-unit edition is in progress. This cumulative release contains complete **Sets and Relations**: **16/722 source units**, fourteen substantive sections and two chapter drivers, including examples, exercises, diagrams and proofs.

- Read [the Gujarati PDF](releases/OpenLogic-gu-Gujr-IN-Sets-Relations.pdf).
- Read [the offline HTML reader](reader/foundations.html), with semantic MathML, Unicode prose and local fonts. Download the source/reader ZIP and open this file locally.
- Edit aligned [Sets](gu/content/sets-functions-relations/sets/sets.tex) and [Relations](gu/content/sets-functions-relations/relations/relations-complete.tex).
- See [edition notes](docs/EDITION_NOTES.md), [coverage](provenance/COVERAGE.json) and [recovered canon reconciliation](provenance/LAPTOP_CANON_RECONCILIATION.json).
- [International translations hub](https://github.com/KokunoYumeto/OpenLogic-translations).

This is an AI-authored translation with actual Gujarati canon consultation, deterministic checks, same-agent semantic comparison, reverse-paraphrase samples and visual inspection. It is not independently certified by native scholars. Provisional terms are identified.
