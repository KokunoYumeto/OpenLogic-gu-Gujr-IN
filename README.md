# ઓપન લોજિક — ગુજરાતી (gu-Gujr-IN)

Gujarati scholarly translation of the Open Logic Project. The complete 722-unit edition is in progress. The first cumulative release contains the complete **Sets** chapter: **7/722 source units**, six substantive sections, including examples, exercises, captions and proofs.

- Read [the Gujarati PDF](releases/OpenLogic-gu-Gujr-IN-Sets.pdf).
- Read [the offline HTML reader](reader/sets.html), with semantic MathML, Gujarati Unicode prose and local fonts. Download the source/reader ZIP and open this file locally.
- Edit the [aligned Gujarati TeX](gu/content/sets-functions-relations/sets/sets.tex).
- See [edition and QA notes](docs/EDITION_NOTES.md) and [machine-readable coverage](provenance/COVERAGE.json).
- [International translations hub](https://github.com/KokunoYumeto/OpenLogic-translations).

This is an AI-authored translation, with cited Gujarati canon consultation, deterministic checks, same-agent semantic comparison, reverse-paraphrase samples and visual inspection. It has not been independently certified by native scholars. Provisional terminology is identified. That uncertainty is recorded for revision, not treated as a human approval gate.

Source authority: [OpenLogicProject/OpenLogic](https://github.com/OpenLogicProject/OpenLogic/tree/9620cc73f9c8e0ad003c514a5d3748f29611c4c0), frozen revision `9620cc73f9c8e0ad003c514a5d3748f29611c4c0`. All 722 raw content-file hashes were verified. Pristine English bytes and component notices are retained in `upstream/`; English source availability is not Gujarati translation coverage.
