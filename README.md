# ઓપન લોજિક — ગુજરાતી (gu-Gujr-IN)

આ સંગ્રહમાં [ઓપન લોજિક પ્રોજેક્ટ](https://github.com/OpenLogicProject/OpenLogic)નું ગુજરાતી ભાષાંતર તૈયાર થાય છે. કુલ 722 સ્રોત એકમોમાંથી **248 એકમો** (OLP-0004–OLP-0251)નું ભાષાંતર અને સંચિત PDF, HTML તથા EPUB પ્રકાશન ચકાસાયું છે. તેમાં અગાઉનાં બધા પ્રકરણો ઉપરાંત સંગણનીયતા ભાગના પુનરાવર્તી વિધેયો અને સંગણનીયતા સિદ્ધાંતનાં સંપૂર્ણ પ્રકરણો છે. 220 વાચક-વિભાગો, 14,210 MathML અભિવ્યક્તિઓ અને 304 PDF પાનાં ધરાવતી આ આવૃત્તિ હજી **722-એકમનો પૂર્ણ ગ્રંથ નથી**. [બન્ને નવા પ્રકરણોની સમીક્ષા](docs/COMPUTABILITY_REVIEW.md) અને [વ્યાપની યંત્રવાચ્ય નોંધ](provenance/COVERAGE.json) તપાસી શકાય છે.

વાંચવા અને ડાઉનલોડ કરવા માટે [સંગણનીયતા સિદ્ધાંત સુધીની v0.18.0 આવૃત્તિ](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/releases/tag/computability-theory-v0.18.0) ખોલો: PDF, પૂર્ણ લખાણની સીધી LaTeX ફાઇલ, સંપૂર્ણ સ્રોત ZIP, નાનું બિલ્ડ-મુખ્ય, EPUB, ઓફલાઇન HTML, ચકાસણી સરવાળા અને QA નોંધ મળે છે. એ જ આઠ ફાઇલો [Zenodo DOI 10.5281/zenodo.22951232](https://doi.org/10.5281/zenodo.22951232) પર સચવાઈ છે; PDF ત્યાં વાંચવા માટેનું પૂર્વદર્શન છે. અહીં [ઓફલાઇન HTML વાચક](reader/computability-theory.html), [EPUB](releases/OpenLogic-gu-Gujr-IN-Computability-Theory.epub), [PDF](releases/OpenLogic-gu-Gujr-IN-Computability-Theory.pdf) અને [પૂર્ણ લખાણની LaTeX ફાઇલ](releases/OpenLogic-gu-Gujr-IN-Computability-Theory-Full-Text.tex) પણ છે. 2,498 ભાષિક ખંડો, 14,203 મૂળ ગણિતીય વિસ્તારો, 1,193 એજન્ટ-આધારિત ઊલટા અર્થવર્ણન નમૂનાઓ અને 197 ચાવીબદ્ધ સુધારા અથવા ઐતિહાસિક ખુલાસાઓ નોંધાયા છે. EPUBCheck 5.3.0એ શૂન્ય સંદેશ આપ્યા; પૂર્ણ-લખાણની TeX ફાઇલે સ્વીકૃત PDFને ત્રણ નિયંત્રિત પાસમાં ચોક્કસ બાઇટ્સ સાથે ફરી બનાવ્યો. છેલ્લાં 44 એકમોનું ભાષાંતર અને તેની સમીક્ષા OpenAI Codex — GPT-6 Sol, Ultra effort દ્વારા થયા; અગાઉનાં 204 એકમો OpenAI Codex — GPT-5.6 Sol, Ultra effort દ્વારા તૈયાર થયા હતા. સ્વતંત્ર ગુજરાતી વિદ્વાનની પ્રમાણિત સમીક્ષા થયેલી નથી.

## અગાઉ પ્રકાશિત 204-એકમની આવૃત્તિ

આગળનો ઐતિહાસિક વિભાગ અગાઉની અનામી રીતે ચકાસાયેલી 204-એકમની આવૃત્તિનો છે. હાલની જાહેર આવૃત્તિ ઉપર દર્શાવેલી 248-એકમની છે.

વાંચવા અને ડાઉનલોડ કરવા માટે [લિન્ડસ્ટ્રોમ સુધીની v0.16.0 આવૃત્તિ](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/releases/tag/lindstrom-v0.16.0) ખોલો. ત્યાં ફાઇલો આ ક્રમમાં સમજાવેલી છે: [PDF](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/releases/download/lindstrom-v0.16.0/OpenLogic-gu-Gujr-IN-Lindstrom.pdf), [આખા લખાણની સીધી LaTeX ફાઇલ](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/releases/download/lindstrom-v0.16.0/OpenLogic-gu-Gujr-IN-Lindstrom-Full-Text.tex), [સંપૂર્ણ સંપાદનીય સ્રોત ZIP](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/releases/download/lindstrom-v0.16.0/OpenLogic-gu-Gujr-IN-Lindstrom-source.zip), નાનું મુખ્ય LaTeX ફાઇલ, EPUB, HTML, ચકાસણી સરવાળા અને ગુણવત્તા નોંધ. એ જ આઠ ફાઇલો [Zenodo DOI 10.5281/zenodo.22865986](https://doi.org/10.5281/zenodo.22865986) પર સચવાઈ છે; PDF ત્યાં વાંચવા માટેનું પૂર્વદર્શન છે.

આ સંગ્રહમાં જ [ઇન્ટરનેટ વિના ચાલતો HTML/MathML વાચક](reader/lindstrom.html), [EPUB](releases/OpenLogic-gu-Gujr-IN-Lindstrom.epub), [અનુરૂપ ગુજરાતી સ્રોત ફાઇલો](gu/content), [બિલ્ડ સૂચનાઓ](docs/BUILD_CUMULATIVE.md), [આવૃત્તિ અને મર્યાદાની નોંધો](docs/EDITION_NOTES.md), [ગુજરાતી સ્વરૂપની નીતિ](docs/GUJARATI_EDITION_SCOPE.md) અને [ભાષાંતરના નિર્ણયો તપાસવાનો પ્રવેશદ્વાર](docs/translation-decisions/START_HERE.md) પણ છે. [વ્યાપની યંત્રવાચ્ય નોંધ](provenance/COVERAGE.json) તથા [અગાઉના ગુજરાતી સ્રોતો સાથેની સરખામણી](provenance/LAPTOP_CANON_RECONCILIATION.json) વધુ તપાસ માટે છે. [આંતરરાષ્ટ્રીય ભાષાંતર કેન્દ્ર](https://github.com/KokunoYumeto/OpenLogic-translations) પરથી બીજી ભાષાઓ મળી શકે છે.

વાચકમાં 12,178 મૂળ MathML સૂત્રો, 15 વર્ણનવાળી આકૃતિઓ અને 175 ચાવીબદ્ધ સ્રોત-સુધારા અથવા મર્યાદાની નોંધો છે. તમામ 260 PDF પાનાં દૃષ્ટિથી તપાસાયા. EPUBCheck 5.3.0એ કોઈ સંદેશ આપ્યો નથી. 204 એકમોના સ્રોત-ચેકપોઇન્ટના 477 નોંધાયેલા ફાઇલ-હૅશ અને પ્રકાશિત આઠ ફાઇલોના બાઇટ્સ તથા SHA-256 સરવાળા અનામી રીતે પાછા વાંચીને ચકાસાયા. વિગત [આવૃત્તિની નોંધો](docs/EDITION_NOTES.md) અને [પ્રકાશન નોંધ](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/releases/tag/lindstrom-v0.16.0)માં છે.

**AI કાર્ય અને સમીક્ષાની સ્થિતિ:** આ 204-એકમની આવૃત્તિનું ભાષાંતર, ગણિતીય સુધારા, સંપાદન, રચના અને એજન્ટ-આધારિત ચકાસણી OpenAI Codex — GPT-5.6 Sol, Ultra effort દ્વારા કરવામાં આવી. આ ગુજરાતી README અને સંબંધિત જાહેર વર્ણનોનું ભાષાકીય સંપાદન OpenAI Codex — GPT-6 Sol, Ultra effort દ્વારા થયું. આ સ્વતંત્ર ગુજરાતી વિદ્વાનની કે માનવીય પ્રમાણિત સમીક્ષા નથી. કેટલીક વિશિષ્ટ પરિભાષા તાત્કાલિક છે; નિર્ણય-નોંધો તથા સ્પષ્ટ સુધારા સમીક્ષા માટે ઉપલબ્ધ છે.
