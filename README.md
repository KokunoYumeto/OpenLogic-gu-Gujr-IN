# ઓપન લોજિક — ગુજરાતી (gu-Gujr-IN)

Gujarati scholarly translation of the Open Logic Project. The full 722-unit edition is in progress. The current cumulative working edition translates **155/722 source units**, comprising 138 substantive sections and seventeen chapter or part drivers. It contains complete Sets, Relations, Functions, Size of Sets, Arithmetization, Infinite Sets, Propositional Logic syntax and semantics, the First-order Logic proof-systems overview, Sequent Calculus, Natural Deduction, Tableaux, Axiomatic Deduction, Completeness, Introduction, and Syntax chapters. The new syntax chapter develops first-order language signatures, terms and formulas, unique readability, main operators, subformulas, formation sequences, free and bound variables, sentences, and capture-avoiding substitution.
