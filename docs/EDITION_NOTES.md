## Disclosed source corrections

Twenty-five keyed notes keep each deliberate departure from the frozen English source reviewable. OLFUN-001–OLFUN-005 repair the empty-domain left-inverse claim, the square-root zero boundary, an `n`/`x` typo, the graph relation type, and the restriction analogy. OLSIZ-001–OLSIZ-012 restore a missing table value, a malformed cofinite sentence, a duplicated pairing family, two free-index characteristic sequences, a finite object in an infinite-sequence codomain, two undefined-function branches, a quantified domain, reversed string indices, a repeated bit flip, malformed three-argument conditional braces, and a duplicate fully qualified exercise label. OLARI-001–OLARI-004 repair a reversed subtraction, the wrong premise in a least-upper-bound proof, three equivalence-class category errors, and a rational/real zero type error. OLINF-001 makes the Dedekind-algebra carrier explicit in a definition and its closure lemma; OLINF-002 states the two cardinality equalities actually proved by the auxiliary Schröder–Bernstein proposition. OLPL-001 removes an unmatched parenthesis from the material-conditional abbreviation; OLPL-002 restores the defined syntactic-identity relation in a formation-sequence proof. Each correction records the frozen source hash, target location, rationale, exact mathematical change where applicable, and semantic and render status.

Uncorrected inherited issues remain separate editorial notes. These include the natural-number diagonal named without a separate assignment, an undefined `X` where a tree base set is `A`, a subtree example that does not explicitly exclude the empty subset, and different local meanings of `R+` in Orders and Operations. Bibliographic titles and names retain their source language.

## Source fidelity and rendering

Editable identities, macro names, labels, citations, links, hierarchy, and attribution are preserved except for the single disclosed duplicate-label repair. Adapters expand article and plural tokens into Gujarati inflections. Set diagrams reproduce the original TikZ paths and colors; function diagrams preserve the source mapping incidence; graph and tree diagrams preserve validated vertices, edges, loops, isolation, and growth direction.

PDF extraction is not used as a proxy for visual correctness because Gujarati shaping can be misreported by extraction tools. The offline reader supplies Unicode Gujarati and native MathML without an external JavaScript runtime. Provisional terminology, source-correction disclosures, and the incomplete 59/722 coverage remain visible to readers.
