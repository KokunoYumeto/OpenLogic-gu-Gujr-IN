## Source fidelity and rendering

Editable identities, macro names, labels, citations, links, hierarchy, and attribution are preserved except for the single disclosed duplicate-label repair. Adapters expand article and plural tokens into Gujarati inflections. Set diagrams reproduce the original TikZ paths and colors; function diagrams preserve the source mapping incidence; graph and tree diagrams preserve validated vertices, edges, loops, isolation, and growth direction.

PDF extraction is not used as a proxy for visual correctness because Gujarati shaping can be misreported by extraction tools. The offline reader supplies Unicode Gujarati and native MathML without an external JavaScript runtime. Provisional terminology, source-correction disclosures, and the incomplete 80/722 coverage remain visible to readers.
