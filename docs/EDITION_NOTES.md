Editable identities, macro names, labels, citations, links, hierarchy, and attribution are preserved except for the single disclosed duplicate-label repair. Set diagrams reproduce the original TikZ paths and colors; function diagrams preserve the source mapping incidence; graph and tree diagrams preserve validated vertices, edges, loops, isolation, and growth direction.
