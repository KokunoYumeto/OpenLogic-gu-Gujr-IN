# સંપૂર્ણ ગુજરાતી આવૃત્તિનું જાહેર સંરક્ષણ અને ચકાસણી

બધા **722 એકમોનો 960-પાનાંનો પાઠ** [GitHub](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/releases/tag/full-edition-v1.0.1) અને [Zenodo DOI 10.5281/zenodo.23030256](https://doi.org/10.5281/zenodo.23030256) પર ખુલ્લો છે. Zenodoની સંકલ્પ-શ્રેણી **22308101** યથાવત્ છે. પહેલાંની [22991323 આવૃત્તિ](https://zenodo.org/records/22991323) તથા તેની નવ જાહેર ફાઇલો ઉપલબ્ધ છે.

OpenAI Codex — **GPT-5.6 Sol અને GPT-6 Sol, Ultra effort** દ્વારા ભાષાંતર, સુધારા, સંપાદન અને પોતાની સમીક્ષા થયાં છે. સ્વતંત્ર ગુજરાતી માનવ નિષ્ણાતનું પ્રમાણન નથી.

બંને પ્રકાશન-સ્થળની દરેક **25 ફાઇલ** અનામી રીતે ડાઉનલોડ કરીને નામ, બાઇટ-સંખ્યા અને SHA-256 સરખાવ્યાં. PDF પ્રથમ, બધું લખાણ ધરાવતી સીધી સંપાદનીય TeX બીજા સ્થાને અને પૂર્ણ સ્રોત ZIP ત્રીજા સ્થાને છે. 19 વધારાની ભાગ-TeX ફાઇલો ઉપલબ્ધ છે. GitHub પોતાની બે સ્રોત-આર્કાઇવ ઉમેરે છે; ત્યાં કુલ 27 ડાઉનલોડ છે, 100ની મર્યાદાથી ઓછા. તેમની અંદરના 2829 પૅકેજ-સ્રોત સભ્યો પણ ચકાસ્યાં.

સંપૂર્ણ ZIPમાં 722 ગુજરાતી તથા 722 અપરિવર્તિત અંગ્રેજી મોડ્યુલો, સંપૂર્ણ master, શૈલી, ચિત્રો, ફોન્ટ, સંદર્ભગ્રંથો, મૂળ પરવાના અને બિલ્ડ માર્ગદર્શિકા છે. સીધી TeXમાંથી ફરી બનાવેલો PDF પ્રકાશિત PDF સાથે બાઇટ-દર-બાઇટ સમાન છે. તેનો SHA-256 `d3ac6296f87722c4de9b5478b31378416586df4142956678e48727c5edd9cea2` છે.

6732 હાલના ખંડોના ચોક્કસ સ્રોત/અનુવાદ બાઇટ્સ અને નોંધાયેલા કૅનન અંશો ચકાસ્યાં. [બધા એકમની ગુજરાતી સમીક્ષા](FULL_READER_EXPERT_REVIEW.gu.md), [270 પરિભાષા-પસંદગી](TERMINOLOGY_REVIEW.gu.md) અને [52 પ્રસંગના ચાર વ્યાકરણ-નિયમ](FULL_READER_GRAMMAR_REVIEW.gu.md) ઉપલબ્ધ છે. જૂની મૂળ નોંધોમાં “બાકી આયાત” કે “હજી સમીક્ષાશે” તે નોંધ લખાઈ હતી ત્યારની સ્થિતિ છે; હાલના બધા 722 એકમ આ પૂર્ણ આવૃત્તિમાં સમાવાયેલા અને અલગ સમીક્ષા સાથે જોડાયેલા છે.

સૂત્રોમાં બાકી રહેલા 66 અંગ્રેજી ગદ્ય પ્રસંગનો ગુજરાતી સુધારો [અલગ સમીક્ષા](FORMULA_ANNOTATION_REVIEW.gu.md)માં છે. બદલાયેલા 28 ખંડની બાઇટ્સ અને ખરેખર ફરી વાંચેલા કૅનન સાક્ષ્ય સાથેના બંધનો ફરી ચકાસ્યાં; ચલ અને ગણિતીય શરતો જાળવ્યાં છે. [પ્રથમ પૂર્ણ આવૃત્તિ 23029704](https://zenodo.org/records/23029704) અને તેની બધી 25 ફાઇલો પણ ખુલ્લી રહે છે.

આખા PDFની પાનાંસીમા અને બુકમાર્ક તપાસ, તથા 133 પસંદ કરેલા પાનાંની વાસ્તવિક દૃશ્ય તપાસ પૂર્ણ છે. નવા અથવા બદલાયેલા 37 પાનાં ખરેખર જોયાં; અગાઉ જોયેલા 96 નમૂનાની PNG બાઇટ-સમાનતા ચકાસી. છ નાનાં overfull hbox ચેતવણીઓ જાળવેલી છે; કાપેલું લખાણ મળ્યું નથી. સંપૂર્ણ 960 પાનાંની વ્યક્તિગત અર્થ-સમીક્ષા કે માનવ પ્રમાણનનો દાવો નથી. મૂળના અધૂરા પુરાવા અને કામચલાઉ વિશિષ્ટ શબ્દો ખુલ્લી નોંધમાં છે.

Zenodoનું મુખ્ય પૂર્વદર્શન ખરેખર PDF બતાવે છે; પ્રથમ પાનું ગુજરાતીમાં યોગ્ય રીતે દેખાયું અને દર્શકે 960 પાનાં બતાવ્યાં. PDF.jsનું ટેક્સ્ટ/સુગમતા સ્તર કેટલાક ગુજરાતી અક્ષરો વિખંડિત કે બદલાવ-ચિહ્નવાળા આપે છે. અન્ય નિષ્કર્ષણ-સાધનો પણ શબ્દવિરામ કે જૂના ગણિતીય ફોન્ટમાં મર્યાદિત છે. ચોક્કસ પાઠ અને સંપાદન માટે TeX તથા ગુજરાતી સમીક્ષા-પાઠ વાપરો.

દરેક જાહેર ફાઇલના નામ, બાઇટ અને હૅશ, સ્રોત-સભ્યો, પૂર્વદર્શન અને તપાસની ચોક્કસ મર્યાદા [યંત્રવાચ્ય અંતિમ નોંધ](../provenance/full-reader/FINAL_PUBLICATION_VERIFICATION.json)માં છે. ZIPની પ્રકાશન-પૂર્વ QA ક્ષણ-નોંધ યથાવત્ છે; આ પ્રકાશન-પછીની ચકાસણી તેને જોડે છે.
