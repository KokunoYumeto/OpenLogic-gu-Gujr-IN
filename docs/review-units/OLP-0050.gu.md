ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{defn}\ollabel{defn:DedekindInfinite}
ગણ $A$ \emph{ડેડેકિન્ડ-અનંત} હોય જો અને માત્ર જો $A$થી $A$ના કોઈ
ઉચિત ઉપગણમાં !!a{injection} હોય. એટલે કે, કોઈ $o \in A$ અને
!!a{injection} $f \colon A \to A$ એવાં હોય કે $o \notin \ran{f}$.
\end{defn}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{defn}\ollabel{defn:DedekindInfinite}
A set $A$ is \emph{Dedekind infinite} iff there is !!a{injection}
from~$A$ to a proper subset of~$A$. That is, there is some $o \in A$
and !!a{injection} $f \colon A \to A$ such that $o \notin \ran{f}$.
\end{defn}
```
