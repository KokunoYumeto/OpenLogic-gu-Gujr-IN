```tex

!G_\Th{T} \liff \lnot \OProv[\Th{T}](\gn{!G_\Th{T}}).
\end{equation}

!!{derivable} in~$\Th{T}$.''

  છે: તે $!G_\Th{T}$
  કે $\lnot !G_\Th{T}$,
  બેમાંથી એકેયને
  !!{derive} કરતું નથી.
\end{proof}
```
