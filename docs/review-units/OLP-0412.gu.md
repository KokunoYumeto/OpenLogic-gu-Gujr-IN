ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{defn}
  મૂળભૂત મોડલ ભાષાનું \emph{નિદર્શન} એ ત્રિક
  $\mModel{M} = \tuple{W, R, V}$ છે, જ્યાં
  \begin{enumerate}
  \item $W$ એ ``જગતો''નો અખાલી ગણ છે,
  \item $R$ એ~$W$ પરનો દ્વિસ્થાની સુલભતા સંબંધ છે, અને
  \item $V$ એવું વિધેય છે જે દરેક !!{propositional
    variable}~$p$ને શક્ય જગતોનો ગણ $V(p)$ આપે છે.
  \end{enumerate}
  $Rww'$ હોય ત્યારે કહીએ કે $w'$ એ~$w$માંથી \emph{સુલભ}
  છે. $w \in V(p)$ હોય ત્યારે કહીએ કે $p$ એ~$w$માં
  \emph{સત્ય} છે.
\end{defn}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{defn}
  A \emph{model} for the basic modal language is a triple $\mModel{M}
  = \tuple{W, R, V}$, where
  \begin{enumerate}
  \item $W$ is a nonempty set of ``worlds,''
  \item $R$ is a binary accessibility relation on~$W$, and
  \item $V$ is a function assigning to each !!{propositional
    variable}~$p$ a set $V(p)$ of possible worlds.
  \end{enumerate}
  When $Rww'$ holds, we say that $w'$ is \emph{accessible
    from}~$w$. When $w \in V(p)$ we say $p$ is \emph{true at}~$w$.
\end{defn}
```
