મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex

of~$\Th{T}$ is !!{c.e.} also. But !!a{formula}~$!A$ is in~$\Th{\bar
T}$ if and only if $\lnot !A$ is in~$\Th{T}$; so $\Th{\bar T} \leq_m
\Th{T}$.
\end{proof}
```
