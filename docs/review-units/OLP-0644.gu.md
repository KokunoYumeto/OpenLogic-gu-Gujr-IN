```tex
\item $\Gamma$ is consistent, and
\item if $\Gamma \subsetneq \Gamma'$, then $\Gamma'$ is inconsistent.
\end{enumerate}
\end{defn}
```

```tex

$\Gamma$ is consistent. Hence, it cannot be the case that $!A \notin
\Gamma$, so $!A \in \Gamma$.
```
