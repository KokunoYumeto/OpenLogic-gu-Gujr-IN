એક જ એજન્ટે પસંદગી વિધેયની બે વ્યાખ્યાઓ, 1883 અને 1904ના સંદર્ભો, સુક્રમિતતા→પસંદગીનો લઘુતમ-ઘટક પુરાવો, પસંદગી→સુક્રમિતતાનો અનંતાતીત પસંદગી-ક્રમ, વિરામ પહેલાંની અંતઃક્ષેપિતા, હાર્ટોગ્સ વડે વિરામ અને અંતિમ એક-એક વ્યાપ્તતા તપાસી. ખાલી A માટે મૂળનો અપરિભાષિત f(A) અને વિરામ પછી અગાઉના મૂલ્યો બદલવાનો દોષ OLMD-147–148માં દૃશ્ય રીતે સુધાર્યો; સૂત્રની અંગ્રેજી શરતો ગુજરાતી કરી.

ચોક્કસ મૂળ વિસ્તાર: `[2689, 3104]`; અનુવાદ વિસ્તાર: `[5429, 6055]`. બાઇટ્સ UTF-8ના છે.

વાંચેલા અંશ: GU-P013, GU-P047, GU-P049, GU-P086.

ગુજરાતી અનુરૂપ પાઠ:

```tex
$f$ પસંદગી વિધેય હોવાથી, વિરામ પહેલાંના
દરેક $\alpha$ માટે
$g(\alpha) = f(A \setminus
\funimage{g}{\alpha}) \in A \setminus
\funimage{g}{\alpha}$, એટલે
$g(\alpha) \notin \funimage{g}{\alpha}$.
તેથી વિરામ પહેલાં
$g(\alpha) = g(\beta)$ હોય, તો
$g(\beta) \notin \funimage{g}{\alpha}$,
એટલે $\beta \notin \alpha$; તેવી જ રીતે
$\alpha \notin \beta$. ત્રિવિભાજનથી
$\alpha = \beta$. આમ વિરામ પહેલાંનું
$g$ !!{injective} છે.
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
Since $f$ is a choice function, for each $\alpha$ (when defined) we have $g(\alpha) =
f(A \setminus \funimage{g}{\alpha}) \in A \setminus
\funimage{g}{\alpha}$; i.e., $g(\alpha) \notin \funimage{g}{\alpha}$.
So if $g(\alpha) = g(\beta)$ then $g(\beta) \notin
\funimage{g}{\alpha}$, i.e., $\beta \notin \alpha$, and similarly
$\alpha \notin \beta$. So $\alpha = \beta$, by Trichotomy. So $g$ is
!!{injective}.
```

## OLP-0596-B015

અગાઉના ગુજરાતી પસંદગી-સુક્રમિતતા, હાર્ટોગ્સના લેમા અને અનંતાતીત પુનરાવર્તનના વિભાગો સામે મૂળ વાંચ્યું. ઐતિહાસિક કૅન્ટર-ઝર્મેલો સંદર્ભો, પસંદગી વિધેયનું ચોક્કસ ક્ષેત્ર અને પુનરાવર્તનની વિરામ-શરત ફરી તપાસી.

ચોક્કસ મૂળ વિસ્તાર: `[3107, 3437]`; અનુવાદ વિસ્તાર: `[6057, 6665]`. બાઇટ્સ UTF-8ના છે.

વાંચેલા અંશ: GU-P013, GU-P047, GU-P049, GU-P086.

ગુજરાતી અનુરૂપ પાઠ:

```tex
હવે નોંધો કે ``થોભો!'' ખરેખર થાય છે;
એટલે એવી કોઈ લઘુતમ ક્રમવાચક સંખ્યા
$\alpha$ છે કે $A = g[\alpha]$.
ઊલટું ધારો; તો દરેક ક્રમવાચક સંખ્યા
$\alpha$ માટે વિરામ પહેલાંનું $g$
!!{injective} હોવાથી
$\cardless{\alpha}{\Pow{A} \setminus
\{\emptyset\}}$ મળે, જે
\olref[hartogs]{HartogsLemma}નો વિરોધ
કરે છે. તેથી
$\funimage{g}{\alpha}=A$ પણ છે.
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
Next, observe that we do stop!{}, i.e.\ that there is some (least) ordinal $\alpha$ such that $A = g[\alpha]$. For suppose otherwise; then as $g$ is !!{injective} we would have $\cardless{\alpha}{\Pow{A} \setminus \{\emptyset\}}$ for
every ordinal $\alpha$, contradicting \olref[hartogs]{HartogsLemma}. Hence also $\ran{g} = A$.
```

## OLP-0596-B016

અગાઉના ગુજરાતી પસંદગી-સુક્રમિતતા, હાર્ટોગ્સના લેમા અને અનંતાતીત પુનરાવર્તનના વિભાગો સામે મૂળ વાંચ્યું. ઐતિહાસિક કૅન્ટર-ઝર્મેલો સંદર્ભો, પસંદગી વિધેયનું ચોક્કસ ક્ષેત્ર અને પુનરાવર્તનની વિરામ-શરત ફરી તપાસી.

ચોક્કસ મૂળ વિસ્તાર: `[3440, 3564]`; અનુવાદ વિસ્તાર: `[6667, 7681]`. બાઇટ્સ UTF-8ના છે.

વાંચેલા અંશ: GU-P013, GU-P047, GU-P049, GU-P086.

ગુજરાતી અનુરૂપ પાઠ:

```tex
આ બધું ભેગું કરતાં
$\funrestrictionto{g}{\alpha}$ એ કોઈ
ક્રમવાચક સંખ્યામાંથી $A$ પર
!!a{bijection} છે. હવે આ $g$ના વિરામ
પહેલાંના ભાગથી
$A$ને સુક્રમિત કરી શકાય.
\sourcecorrection{OLMD-148}{મૂળમાં વિરામની
પહેલી ઘડીએ બધા $\delta\leq\alpha$ માટે
$g(\delta)=A$ લખાયું છે; એમ કરવાથી
અગાઉની પસંદગીઓ જ નષ્ટ થાય. અહીં
$\delta\geq\alpha$ કર્યું છે અને
અંતઃક્ષેપ/એક-એક વ્યાપ્તતાનો દાવો ફક્ત
વિરામ પહેલાંના $\funrestrictionto{g}{\alpha}$
માટે કર્યો છે; વિરામ પછીનું સ્થિર મૂલ્ય
આ દાવામાં આવતું નથી.}
\end{proof}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
Assembling these facts, $g$ is !!a{bijection} from some ordinal to $A$. Now $g$ can be used to well-order $A$.
\end{proof}
```
