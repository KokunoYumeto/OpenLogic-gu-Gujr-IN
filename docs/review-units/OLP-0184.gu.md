ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{defn}
\ollabel{defn:reduct}
ધારો કે $\Lang L \subseteq \Lang L'$, $\Struct M$ એ
$\Lang L$-!!{structure} છે અને $\Struct M'$ એ
$\Lang L'$-!!{structure} છે. નીચેની શરતો સંતોષાય તો અને માત્ર તો
$\Struct M$ને $\Lang L$ પરનું $\Struct M'$નું \emph{ન્યૂનરૂપ} અને
$\Struct M'$ને $\Lang L'$ સુધીનો $\Struct M$નો \emph{વિસ્તાર} કહીએ:
\begin{enumerate}
\item $\Domain{M} = \Domain{M'}$
\item દરેક !!{constant}~$c \in \Lang L$ માટે $\Assign{c}{M} =
  \Assign{c}{M'}$.
\item દરેક !!{function}~$f \in \Lang L$ માટે $\Assign{f}{M} =
  \Assign{f}{M'}$.
\item દરેક !!{predicate}~$P \in \Lang L$ માટે $\Assign{P}{M} =
  \Assign{P}{M'}$.
\end{enumerate}
\end{defn}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{defn}
\ollabel{defn:reduct}
Suppose $\Lang L \subseteq \Lang L'$, $\Struct M$ is an
$\Lang L$-!!{structure} and $\Struct M'$ is an $\Lang L'$-!!{structure}.
$\Struct M$ is the \emph{reduct} of $\Struct M'$ to $\Lang L$, and
$\Struct M'$ is an \emph{expansion} of $\Struct M$ to $\Lang L'$ iff
\begin{enumerate}
\item $\Domain{M} = \Domain{M'}$
\item For every !!{constant}~$c \in \Lang L$, $\Assign{c}{M} =
  \Assign{c}{M'}$.
\item For every !!{function}~$f \in \Lang L$, $\Assign{f}{M} =
  \Assign{f}{M'}$.
\item For every !!{predicate}~$P \in \Lang L$, $\Assign{P}{M} =
  \Assign{P}{M'}$.
\end{enumerate}
\end{defn}
```
