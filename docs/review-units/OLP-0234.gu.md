\begin{thm}
\ollabel{thm:no-univ}
કોઈ સર્વવ્યાપી સંગણનીય વિધેય નથી. બીજા શબ્દોમાં, જો

```tex
\begin{thm}
\ollabel{thm:no-univ}
There is no universal computable function. In other words, any
function $\fn{Un}'(k, x)$ which is such that if $f(x)$ is a total
computable function, then there is a natural number~$k$ such that
$f(x) = \fn{Un}'(k,x)$ for every~$x$, is not computable.
\end{thm}
```

ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{proof}
આ સાદી વિકર્ણીકરણ સાબિતી છે: $\fn{Un}'(k,x)$ સંપૂર્ણ અને સંગણનીય
હોય, તો
\[
d(x) = \fn{Un}'(x, x) + 1
\]
પણ સંપૂર્ણ અને સંગણનીય થાય. પરંતુ વ્યાખ્યા મુજબ $d(k)$ અને
$\fn{Un}'(k,k)$ સમાન નથી. તેથી દરેક $k$ માટે $d(x)$ અને
$\fn{Un}'(k, x)$નાં મૂલ્યો ઓછામાં ઓછા એક~$x$ પર, એટલે $x = k$
પર, જુદાં પડે છે.
\end{proof}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{proof}
The proof is a simple diagonalization: if $\fn{Un}'(k,x)$ were total
and computable, then
\[
d(x) = \fn{Un}'(x, x) + 1
\]
would also be total and computable. However, by definition, $d(k)$ is
not equal to $\fn{Un}'(k,k)$. Hence, for every $k$, the values of
$d(x)$ and~$\fn{Un}'(k, x)$ differ for at least one~$x$, namely $x = k$.
\end{proof}
```
