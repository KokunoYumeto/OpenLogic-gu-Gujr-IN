મૂળ ગુજરાતી ગણ-સભ્ય અને સાન્ત-અનંતના ગદ્ય તથા પ્રકાશિત ગણસંબંધના સુક્રમિત, લઘુતમ અને ત્રિવિકલ્પતા વપરાશ સામે સ્થિર મૂળના ક્રમવાચક સભ્યતા-પુરાવા વાંચ્યા. મૂળ ગુજરાતી કૅન્ટૉર નામપ્રયોગ તપાસ્યો; પરંપરિત ગણ અને અનંતાતીત અનુમાનના વિશિષ્ટ સંયુક્ત નામો સૂત્રો પરથી પારદર્શક રીતે લીધાં છે.

એક જ એજન્ટે ક્રમવાચક સંખ્યાના સભ્યોની ક્રમવાચકતા અને પરંપરિતતા, અનંતાતીત અનુમાનમાં ગુણધર્મ ધરાવતા ઉપગણના લઘુતમ સાક્ષી, બેવડા અનુમાનની બે સમાવેશ-દિશાઓ, ત્રિવિકલ્પતા, બધી ક્રમવાચક સંખ્યાઓ ગણ ન બને તેનો વિરોધાભાસ, ઐતિહાસિક અવતરણ અને છેલ્લા ચાર પરિણામ-સ્વાધ્યાયોની શરતો તપાસી.

મૂળ સમીક્ષાનો ખંડ 5: ક્રમવાચક સંખ્યાનો દરેક સભ્ય પણ ક્રમવાચક હોય તે લેમા જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 6: bનું alphaનું ઉપગણ હોવું અને alpha પર સુક્રમથી b પર સુક્રમ મળવો તે પહેલી દિશા જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 7: x in c in bથી x,c,b in alpha, ત્યાં સભ્યતા-સંબંધની પરંપરિતતા અને પછી x in b દ્વારા bની પરંપરિતતા બતાવવાનું જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 8: alphaના બધા સભ્યો ક્રમવાચક છે તે અચૂક ઉપગણ-રૂપ સમાનતા જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 9: અગાઉના લેમાથી તાત્કાલિક ફલિતાર્થની સાબિતી જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 10: આગળના અનુમાન અને ત્રિવિકલ્પતા ક્રમવાચક સંખ્યાઓના વર્ગ પર સભ્યતા-સુક્રમનો સાર આપે તે સંદર્ભ જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 11: ગુણધર્મ ધરાવતી ક્રમવાચક સંખ્યા હોય તો એવી એક મળે જેના કોઈ સભ્યમાં ગુણધર્મ નથી એ પૂર્ણ અનુમાન-નિવેદન અને પરિમાણકોના મર્યાદિત વ્યાપની નોંધ જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 12: મૂળનું આખા alphaમાંથી યોગ્ય લઘુતમ સભ્ય પસંદ કરવાનું અસ્પષ્ટ પગલું phi સંતોષતા ઉપગણથી સ્પષ્ટ કર્યું; OLMD-116 દેખીતું છે. નિષ્ક્રિય મૂળ ટિપ્પણી અને સમકક્ષ અનુમાન-પ્રરૂપ જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 13: બે ક્રમવાચક સંખ્યાઓ વચ્ચે સભ્યતા, સમાનતા કે ઉલટી સભ્યતા પૈકી એક હોય તે ત્રિવિકલ્પતા જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 14: તુલનીયતાની ત્રણ શક્યતાઓની વ્યાખ્યા અને બેવડા અનુમાનની પદ્ધતિ જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 15: alphaના સભ્યો સામે બધા ક્રમવાચકો અને betaના સભ્યો સામે alphaની બે અનુમાન-ધારણાઓ, પછી બંને બાહ્ય અને આંતરિક નિષ્કર્ષોની વ્યવસ્થા જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 16: gamma in alpha માટે beta સાથે તુલનીયતા; gamma=beta અથવા beta in gammaથી beta in alphaનો વિરોધાભાસ; તેથી gamma in beta અને alpha subset beta જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 17: બીજી અનુમાન-ધારણા વડે beta subset alpha, પછી સમાનતા, અને સભ્યતાને < તરીકે લખવાનો માત્ર સંકેતપરિચય જળવાય છે; અપ્રચલિત વિકલ્પ ફૂટનોટમાં છે.

મૂળ સમીક્ષાનો ખંડ 18: છેલ્લાં બે પરિણામોના ફલિતાર્થ અને નવા સંકેતનો પ્રથમ ઉપયોગ રજૂ થાય છે.

મૂળ સમીક્ષાનો ખંડ 19: phi સંતોષતી લઘુતમ ક્રમવાચક સંખ્યા, સ્વસભ્યતા ન હોવી અને સભ્યતાની પરંપરિતતા ત્રણેય ચોક્કસ નિવેદનો જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 20: સુક્રમના અગાઉના પુરાવા સાથેની ટૂંકી સાબિતી-સૂચના જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 21: ત્રિવિકલ્પતાની સાબિતીમાં બીજી સમાવેશ-દિશા વાચકને પૂર્ણ કરાવતો સ્વાધ્યાય જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 22: પરંપરિત ક્રમવાચક સંખ્યાઓના ગણનું ક્રમવાચક હોવા સાથેનું બરાબર-ત્યારે-જ નિવેદન જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 23: ડાબેથી જમણે સભ્ય-લેમા અને જમણેથી ડાબે અનુમાન તથા ત્રિવિકલ્પતા વડે સભ્યતા-સુક્રમની દિશાઓ જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 24: વર્ગને સુક્રમિત કહેતાં પણ તે ગણ ન હોય તે બાબતની સાવચેતી બુરાલી–ફૉર્ટી પરિણામ પહેલાં જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 25: બધી ક્રમવાચક સંખ્યાઓનો ગણ નથી તે પ્રમેય અને બુરાલી–ફૉર્ટી નામ જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 26: કલ્પિત O પરંપરિત ગણ થાય, તેથી પોતે ક્રમવાચક થાય, તેથી O in O મળે અને અસ્વસભ્યતા સાથે વિરોધાભાસ થાય તે દલીલ જળવાય છે.

મૂળ સમીક્ષાનો ખંડ 27: બુરાલી–ફૉર્ટી, કૅન્ટૉરના 1899 પત્ર અને વાન હેયેનૉર્ટના પૃષ્ઠ 105ના મૂળ સંદર્ભવાળું અવતરણ અનુવાદિત છે; વ્યક્તિગત અને સામૂહિક સુક્રમનો ગણ-વર્ગ ભેદ જળવાય છે.

ચોક્કસ મૂળ વિસ્તાર: `[1515, 1835]`; અનુવાદ વિસ્તાર: `[2680, 3168]`. બાઇટ્સ UTF-8ના છે.

વાંચેલા અંશ: GU-P013, GU-P049.

ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{thm}[અનંતાતીત અનુમાન]\ollabel{ordinductionschema}
કોઈ પણ સૂત્ર $\phi(x)$ માટે:
\[
	\text{જો }\exists \alpha \phi(\alpha)\text{, તો }\exists \alpha(\phi(\alpha)
	\land  (\forall \beta \in \alpha) \lnot \phi(\beta))
\]
અહીં દર્શાવેલા પરિમાણકો પરોક્ષ રીતે ક્રમવાચક
સંખ્યાઓ સુધી મર્યાદિત છે.
\end{thm}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{thm}[Transfinite Induction]\ollabel{ordinductionschema}
For any formula $\phi(x)$: 	
\[
	\text{if }\exists \alpha \phi(\alpha)\text{, then }\exists \alpha(\phi(\alpha)
	\land  (\forall \beta \in \alpha) \lnot \phi(\beta))
\]
where the displayed quantifiers are implicitly restricted to ordinals.
\end{thm}
```

ચોક્કસ મૂળ વિસ્તાર: `[7521, 7664]`; અનુવાદ વિસ્તાર: `[13786, 13984]`. બાઇટ્સ UTF-8ના છે.

વાંચેલા અંશ: GU-P013, GU-P049.

ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{prop}\ollabel{ordinalsaresubsets}
કોઈ પણ ક્રમવાચક સંખ્યાઓ
$\alpha, \beta$ માટે
$\alpha \subseteq \beta \lor \beta \subseteq \alpha$.
\end{prop}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{prop}\ollabel{ordinalsaresubsets}
$\alpha \subseteq \beta \lor \beta \subseteq \alpha$, for any ordinals
$\alpha, \beta$.
\end{prop}
```

## OLP-0553-B031

મૂળ ગુજરાતી ગણ-સભ્ય અને સાન્ત-અનંતના ગદ્ય તથા પ્રકાશિત ગણસંબંધના સુક્રમિત, લઘુતમ અને ત્રિવિકલ્પતા વપરાશ સામે સ્થિર મૂળના ક્રમવાચક સભ્યતા-પુરાવા વાંચ્યા. મૂળ ગુજરાતી કૅન્ટૉર નામપ્રયોગ તપાસ્યો; પરંપરિત ગણ અને અનંતાતીત અનુમાનના વિશિષ્ટ સંયુક્ત નામો સૂત્રો પરથી પારદર્શક રીતે લીધાં છે.

ચોક્કસ મૂળ વિસ્તાર: `[7667, 7970]`; અનુવાદ વિસ્તાર: `[13986, 14397]`. બાઇટ્સ UTF-8ના છે.

વાંચેલા અંશ: GU-P013, GU-P049.

ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{proof}
જો $\alpha \in \beta$, તો $\beta$
પરંપરિત હોવાથી $\alpha \subseteq \beta$.
એ જ રીતે, જો $\beta \in \alpha$,
તો $\beta \subseteq
\alpha$. અને જો $\alpha = \beta$,
તો $\alpha \subseteq \beta$ અને
$\beta \subseteq \alpha$.
તેથી \olref{ordtrichotomy} મુજબ
દલીલ પૂરી થાય છે.
\end{proof}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{proof}
If $\alpha \in \beta$, then $\alpha \subseteq \beta$ as $\beta$ is
transitive. Similarly, if $\beta \in \alpha$, then $\beta \subseteq
\alpha$. And if $\alpha = \beta$, then $\alpha \subseteq \beta$ and
$\beta \subseteq \alpha$. So by   \olref{ordtrichotomy} we are done.
\end{proof}
```
