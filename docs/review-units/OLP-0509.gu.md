## OLP-0509-B007

પ્રકાશિત ગુજરાતી પૂર્ણતા-શબ્દપ્રયોગ અને સમીક્ષિત લિન્ડનબાઉમ તથા સત્યતા સહાયક પ્રમેય સામે સ્થિર મૂળનો પ્રતિનિદર્શ તર્ક અને ત્રણ કસરતો સરખાવ્યાં.

ચોક્કસ મૂળ વિસ્તાર: `[337, 963]`; અનુવાદ વિસ્તાર: `[370, 1272]`. બાઇટ્સ UTF-8ના છે.

વાંચેલા અંશ: GU-P065, GU-P074.

ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{proof}
  પ્રતિપક્ષી વિધાન સાબિત કરીએ: ધારો કે $\Gamma \Proves/ !A$.
  ત્યારે \olref[lin]{lem:lindenbaum} મુજબ એવો અભાજ્ય ગણ
  $\Gamma^* \supseteq \Gamma$ છે કે $\Gamma^* \Proves/ !A$.
  \olref[mod]{defn:canonical-model}માં વ્યાખ્યાયિત
  $\Gamma^*$ માટેનું કૅનોનિકલ નિદર્શ~$\mModel{M(\Gamma^*)}$
  લો. દરેક $!B \in \Gamma$ માટે $\Gamma^* \Proves !B$.
  નોંધો કે $\Gamma^*(\emptyseq) = \Gamma^*$.
  સત્યતા સહાયક પ્રમેય (\olref[tru]{lem:truth}) મુજબ
  બધા $!B \in \Gamma$ માટે
  $\mSat{M(\Gamma^*)}{!B}[\emptyseq]$ અને
  $\mSat/{M(\Gamma^*)}{!A}[\emptyseq]$ મળે છે.
  આથી $\Gamma \Entails/ !A$.
\end{proof}
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
\begin{proof}
  We prove the contrapositive: Suppose $\Gamma \Proves/ !A$. Then by
  \olref[lin]{lem:lindenbaum}, there is a prime set~$\Gamma^*
  \supseteq \Gamma$ such that $\Gamma^* \Proves/ !A$. Consider the
  canonical model~$\mModel{M(\Gamma^*)}$ for $\Gamma^*$ as defined in
  \olref[mod]{defn:canonical-model}. For any $!B \in \Gamma$, $\Gamma^*
  \Proves !B$. Note that $\Gamma^*(\emptyseq) = \Gamma^*$. By the Truth
  Lemma (\olref[tru]{lem:truth}), we have
  $\mSat{M(\Gamma^*)}{!B}[\emptyseq]$ for all $!B \in \Gamma$ and
  $\mSat/{M(\Gamma^*)}{!A}[\emptyseq]$. This shows that $\Gamma
  \Entails/ !A$.
\end{proof}
```
