```tex

    have that if $\mSat{M}{!A_i}[w]$ then $\mSat{M}{!A_n}[w]$. Since
    $\Gamma \Entails !A_i$, $\mSat{M}{!A_i}[w]$. So,
    $\mSat{M}{!A_n}[w]$, as we wanted to show.
  \end{enumerate}
\end{proof}
```
