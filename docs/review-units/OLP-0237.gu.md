```tex
\begin{defn}

  $S$~is computable iff the function

\Char{S}(x) =
\begin{cases}
1 & \text{if $x \in S$} \\
0 & \text{otherwise}
\end{cases}
\]
is computable. Similarly, a relation $R(x_0, \dots, x_{k-1})$ is
computable if and only if its characteristic function is.
```
