```tex
$\True$ અને $\False$માં માત્ર એક વધુ મૂલ્ય~$\Undef$ ઉમેરીએ,
તો ત્રિમૂલ્ય તર્કશાસ્ત્ર મળે છે. એક જ વધારાનું સત્યમૂલ્ય
હોવા છતાં $\lnot$, $\land$, $\lor$ અને $\lif$ માટે
સત્યવિધેયો વ્યાખ્યાયિત કરવાની ઘણી રીતો છે. પછી કોઈ
તર્કશાસ્ત્ર આ સત્યવિધેયોના કોઈ પણ સંયોજનનો ઉપયોગ કરી શકે છે;
ઉપરાંત માત્ર $\True$ને નિર્દિષ્ટ ગણવું કે $\True$ અને~$\Undef$
બંનેને નિર્દિષ્ટ ગણવાં, એ પસંદગી પણ છે.
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
If we just add one more value~$\Undef$ to $\True$ and $\False$, we get a
three-valued logic. Even though there is only one more truth value,
the possibilities for defining the truth-functions for $\lnot$,
$\land$, $\lor$, and $\lif$ are quite numerous. Then a logic might use
any combination of these truth functions, and you also have a choice
of making only $\True$ designated, or both $\True$ and~$\Undef$.
```
