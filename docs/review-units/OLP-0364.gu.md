```tex
  જેમ, $\Lambda$-પદો પર ``પ્રક્ષેપિત'' કરવા પડે.
  જોકે વાચક આવાં $\Lambda$-પદો પરના વિધેયો કેવી રીતે વ્યાખ્યાયિત થાય તે
  સાહજિક રીતે સમજી શકશે એમ માનીએ છીએ.
\end{editorial}
\end{document}

```
