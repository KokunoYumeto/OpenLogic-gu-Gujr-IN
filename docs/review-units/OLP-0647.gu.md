મૂળ ગુજરાતી તર્ક-ગદ્ય GU-P075નું વાંચન કરીને ખુલાસાની શૈલી તપાસી. પ્રકાશિત ગુજરાતી Open Logicનાં સામાન્ય પુનરાવર્તી વિધેયો અને સંગણનીય વિધેયોના પાઠમાં નિયમિત, અનિયત મર્યાદા સુધીની શોધ, પ્રક્ષેપો અને સંયોજનના સીધા પ્રયોગો જોયા. સ્થિર અંગ્રેજી legacy વિભાગને અને તેની વિસ્તૃત સમાનાંતર રચનાઓમાં સંયોજન તથા લઘુત્તમીકરણના પુરાવા સરખાવ્યા.

ચોવીસ કાચા ખંડ, 134 સુધારણા-અનુરૂપ ગણિતીય અવકાશો, બે eqnarray કોષ્ટકોની તમામ ગુજરાતી લખાણ-ટિપ્પણીઓ, ત્રણ લેમ્મા, ત્રણ સાબિતી અને એક explain પરિચ્છેદ સરખાવ્યાં. સંયોજનમાં બધા મધ્યવર્તી ચલોનો વ્યાપ સુધાર્યો; આગમન-સાબિતીના છૂટી ગયેલા મધ્યવર્તી પગલાં અને ક્રમદોષ દૃશ્ય નોંધ્યા; છેલ્લા લેમ્માના પાયામાં ન લખાયેલી વિપરીત દિશા અને બાકી રહેલું આગમન-પગલું પૂર્ણ થયાનું માન્યું નથી.

મૂળ સમીક્ષાનો ખંડ 4: $C$નાં વિધેયો અને $\Th{Q}$માં પ્રતિનિધિત્વનું શીર્ષક, inc/req/cre ઓળખ સાથે, સાચવ્યું.

મૂળ સમીક્ષાનો ખંડ 5: દરેક $k$-સ્થાની વિધેયને $!A_f$ આપવાનું અંતિમ લક્ષ્ય અને બધા આર્ગ્યુમેન્ટ જાળવ્યાં.

મૂળ સમીક્ષાનો ખંડ 6: અસમાન પ્રાકૃતિક સંખ્યાઓના સંખ્યાચિહ્નો $Q$માં અસમાન સાબિત થાય એવો લેમ્મા અચળ છે.

મૂળ સમીક્ષાનો ખંડ 7: $n$ પરનું બહારનું આગમન અને દરેક $m$ માટેનો દાવો બરાબર છે.

મૂળ સમીક્ષાનો ખંડ 8: $n=0$ અને $m=k+1$થી શૂન્ય ઉત્તરગામી નથી એવું સ્વયંસિદ્ધિ મૂકી પાયો જાળવ્યો.

મૂળ સમીક્ષાનો ખંડ 9: ઉત્તરગામીની એક-એકતા, આગમન-પરિકલ્પના અને modus ponensથી અસમાનતા મળે તે ક્રમ જાળવ્યો.

મૂળ સમીક્ષાનો ખંડ 10: $\Th{Q}$ની બહારના આગમન અને જુદા સંખ્યાચિહ્નોના અર્થનો ભેદ સ્પષ્ટ છે.

મૂળ સમીક્ષાનો ખંડ 11: છ મૂળભૂત પ્રકારો અને સરવાળાના મૂલ્ય તથા એકમાત્રતા માટેના બંને સૂત્રો અચળ છે.

મૂળ સમીક્ષાનો ખંડ 12: સંયોજનમાં $f$ અને $g_i$ના આર્ગ્યુમેન્ટ અચળ છે; OLMD-181થી અંતિમ $!A_f$ને બધા અસ્તિત્વવાચક પરિમાણકોના વ્યાપમાં મૂક્યું.

મૂળ સમીક્ષાનો ખંડ 13: નિયમિત $g$ પરની અનિયત શોધ અને પહેલું શૂન્ય મૂલ્ય શોધતું પ્રતિનિધિત્વ સૂત્ર જાળવ્યું.

મૂળ સમીક્ષાનો ખંડ 14: આગળના લેમ્માઓને પૂરક આધાર તરીકે રજૂ કર્યા; અહીં પૂર્ણ ઔપચારિક સાબિતીનો દાવો કર્યો નથી.

મૂળ સમીક્ષાનો ખંડ 15: દરેક નિશ્ચિત $n$ માટે ઉત્તરગામી અને સરવાળાની સમાનતા $\Th{Q}$માં સાબિત થાય છે તે જ દાવો છે.

મૂળ સમીક્ષાનો ખંડ 16: નિશ્ચિત સંખ્યાચિહ્નો માટેના લેમ્મા અને $Q$માં અસાબિત સર્વવાચી વિધાન વચ્ચેનો ભેદ જાળવ્યો.

મૂળ સમીક્ષાનો ખંડ 17: પાયો અને આગમન-સાંકળનાં સૂત્રો જાળવ્યાં; eqnarrayની છ અંગ્રેજી ટિપ્પણીઓ ગુજરાતી કરી અને OLMD-182થી બીજા પગલાનું છોડાયેલું કારણ નોંધ્યું.

મૂળ સમીક્ષાનો ખંડ 18: $0$ કરતાં નાનું કશું નથી અને નિશ્ચિત ઉત્તરગામી કરતાં નાની વસ્તુઓનું વિસંયોજન—બંને વિધાનો જાળવ્યાં.

મૂળ સમીક્ષાનો ખંડ 19: ઔપચારિક નિષ્પત્તિના માત્ર સંકેતો આપવાનો મૂળ મર્યાદિત આશય જાળવ્યો.

મૂળ સમીક્ષાનો ખંડ 20: $x=0$ અને $x=z'$ના બે કિસ્સાઓમાં $x<0$ના વિરોધાભાસને જાળવી સર્વવાચી નિષ્કર્ષ બંને પછી મૂક્યો.

મૂળ સમીક્ષાનો ખંડ 21: $x<1$થી $x=0$ની પાયાની દિશા અને $<$નો અસ્તિત્વવાચી સાક્ષી અચળ છે.

મૂળ સમીક્ષાનો ખંડ 22: $x$ ઉત્તરગામી હોવાની ધારણા $z<0$ સુધી લઈ જઈ વિરોધ મેળવ્યો; OLMD-184થી બાકી વિપરીત દિશા અને આગમન-પગલાની ગેરહાજરી સ્પષ્ટ કરી.

મૂળ સમીક્ષાનો ખંડ 23: સંગણનીયતા અને પ્રતિનિધિત્વની સમકક્ષતા, વિસ્તરણો/અર્થઘટન અને પેયાનો તથા ઝેર્મેલો--ફ્રેન્કેલ ઉદાહરણોના દાવા જાળવ્યા.

We have shown that the set of computable functions can be
characterized as the set of functions representable in $\Th{Q}$. In fact,
the proof is more general. From the definition of representability, it
is not hard to see that any theory extending $\Th{Q}$ (or in which one can

conversely, in any !!{derivation} system in which the notion of proof is
computable, every representable function is computable. So, for
example, the set of computable functions can be characterized as the
set of functions represented in Peano arithmetic, or even Zermelo
Fraenkel set theory. As G\"odel noted, this is somewhat surprising.
We will see that when it comes to provability, questions are very
sensitive to which theory you consider; roughly, the stronger the
axioms, the more you can prove. But across a wide range of axiomatic
theories, the representable functions are exactly the computable ones.
