વાંચેલા ગુજરાતી અવતરણો ગણ, પ્રાચલ અને ચોક્કસ સંકેતીકરણના શબ્દપ્રયોગને આધાર આપે છે; લૅમ્બડા કલનનાં વિશિષ્ટ પદો અગાઉના ગુજરાતી મસદ્દા સાથે સરખાવ્યા છે. ઔપચારિક રચના અને અર્થ સ્થિર અંગ્રેજી મૂળથી નક્કી કર્યા છે.

ગુજરાતી અનુરૂપ પાઠ:

```tex
\begin{defn}[પદો] \ollabel{defn:term}
લૅમ્બડા કલનનાં \emph{પદો}નો ગણ આગમનથી આ રીતે વ્યાખ્યાયિત થાય છે:
\begin{enumerate}
  \item \ollabel{defn:term-var} $x$ ચલ હોય તો $x$ પદ છે.
  \item \ollabel{defn:term-abs} $x$ ચલ અને $M$ પદ હોય તો
    $(\lambd[x][M])$ પદ છે.
  \item \ollabel{defn:term-app} $M$ અને $N$ બંને પદો હોય તો
```

```tex
\begin{defn}[Terms] \ollabel{defn:term}
The set of \emph{terms} of the lambda calculus is defined inductively by:
\begin{enumerate}
  \item \ollabel{defn:term-var} If $x$ is a variable, then $x$ is a
    term.
  \item \ollabel{defn:term-abs} If $x$ is a variable and $M$ is a
    term, then $(\lambd[x][M])$ is a term.
  \item \ollabel{defn:term-app} If both $M$ and $N$ are terms, then
    $(MN)$ is a term.
\end{enumerate}
\end{defn}
```

ચોક્કસ મૂળ વિસ્તાર: `[1180, 1841]`; અનુવાદ વિસ્તાર: `[1665, 2914]`. બાઇટ્સ UTF-8ના છે.

ગુજરાતી અનુરૂપ પાઠ:

```tex
ઉપર વ્યાખ્યાયિત પદોમાં બધા જરૂરી કૌંસ છે. આ ક્યારેક ભારે પડે છે;
દાખલા તરીકે પદ
$(\lambd[x][((\lambd[x][x])(\lambd[x][(xx)]))])$ જુઓ. કૌંસ
છોડી શકાય તે માટે આપણે આગળ નિયમો આપીશું. જોકે, આ ઔપચારિક

$(\lambd[x][((\lambd[x][x])(\lambd[x][(xx)]))])$ પદની રચનાનું
છેલ્લું પગલું અમૂર્તીકરણ જ હોવું જોઈએ, જેમાં !!{parameter}~$x$ છે.
તે પદ~$((\lambd[x][x])(\lambd[x][(xx)]))$માંથી અમૂર્તીકરણ વડે
બને છે; આ બીજું પદ બે પદોનો અનુપ્રયોગ છે. તે બંને પદો પોતપોતે
અમૂર્તીકરણથી બને છે, અને આ રીતે આગળ જઈ શકાય છે.
```

મૂળ અંગ્રેજી સરખામણી-પાઠ:

```tex
The terms defined above are fully parenthesized. This can get rather
cumbersome, as the term
$(\lambd[x][((\lambd[x][x])(\lambd[x][(xx)]))])$ demnostrates. We will
introduce conventions for avoiding parentheses.  However, the official
definition makes it easy to determine how a term is constructed
according to \olref{defn:term}. For example, the last step of forming
the term $(\lambd[x][((\lambd[x][x])(\lambd[x][(xx)]))])$ must be
abstraction where the !!{parameter} is~$x$. It results by abstraction
from the term $((\lambd[x][x])(\lambd[x][(xx)]))$, which is an
application of two terms. Each of these two terms is the result of an
abstraction, and so on.
```
