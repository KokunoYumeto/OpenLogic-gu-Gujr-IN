# ગુજરાતી પરિભાષા અને સ્રોતો

કોઈ સંજ્ઞા અથવા ગદ્યપ્રયોગ માટે કયો ગુજરાતી સ્રોત જોવામાં આવ્યો હતો તે અહીં શોધી શકાય છે. [પરિભાષાની સૂચિ](TERM_DECISIONS.jsonl)માં અંગ્રેજી શબ્દ, ગુજરાતી પ્રયોગ અને સંબંધિત ઉતારાના ઓળખક્રમ આપેલા છે. એક જ શબ્દ માટે જુદા નિર્ણય મળે ત્યારે તેનો સંદર્ભ અને નિર્ણયની સ્થિતિ પણ જુઓ.

દાખલા તરીકે, `GU-T001`માં અંગ્રેજી *set* માટે **ગણ** શબ્દ આપેલો છે. તેમાં દર્શાવેલા `GU-P001`ને [ઉતારાની સૂચિ](CANON_PASSAGES.jsonl)માં શોધો. તેનો સ્રોત `GU-GSSTB-MATH11` છે. [ગ્રંથસૂચિ](CANON_SOURCES.jsonl)માં તેની કડી છે. ગુજરાતી ધોરણ ૧૧ના ગણિતના આ પુસ્તકમાં છાપેલું પાનું ૩ જુઓ (PDFનું પાનું ૧૫). સ્રોતનો ઉપયોગ કરતી વખતે નવી વ્યાખ્યા અથવા દલીલનો અર્થ પણ આ પ્રયોગ સાથે બંધબેસે છે કે કેમ તે તપાસો.

[પાઠ અને ઉતારા વચ્ચેના સંબંધો](SEGMENT_CANON.jsonl)માં `passage` એક ઉતારા વિશેની અને `unit` આખા એકમ વિશેની નોંધ દર્શાવે છે. દરેક નોંધમાં અંગ્રેજી અને ગુજરાતી લખાણના UTF-8 બાઇટનો આરંભ, અંત અને SHA-256 છે. અંતનો બાઇટ તે ગાળામાં સામેલ નથી. [અન્ય પસંદગીઓની સૂચિ](CHOICE_REFERENCES.jsonl) મૂળ નિર્ણય અને તેના સ્રોતોના ઓળખક્રમ જોડે છે. તેમાં `binding_at_edition_ref`નો આધાર [ગુજરાતી આવૃત્તિની આ પ્રત](https://github.com/KokunoYumeto/OpenLogic-gu-Gujr-IN/tree/3636bbc6298a4b07579bc9e7fdeddde1f2d3d361) છે.

અંગ્રેજી મૂળ કે ગુજરાતી પાઠ સુધરે ત્યારે જૂની નોંધનો ગાળો બદલાઈ શકે છે. સુધારા માટે તૈયાર કરેલા પૅકેટમાં `source_matches` અને `target_matches` પરથી જાણી શકાય છે કે અગાઉ નોંધેલો પાઠ હજી એ જ સ્થાને મળે છે કે કેમ. `covers_current_unit` આખા વર્તમાન અંગ્રેજી અને ગુજરાતી એકમને આવરી લેતી મેળ ખાતી નોંધ દર્શાવે છે. અગાઉની નોંધ ન મળે ત્યારે મૂળ ઉતારો, હાલનું ગુજરાતી લખાણ અને ટાંકેલો સ્રોત સાથે વાંચવા જોઈએ. બાઇટનો મેળ અગાઉનું લખાણ ઓળખાવે છે. નવી દલીલમાં યોગ્ય શબ્દ નક્કી કરવા તેનો અર્થ તપાસવો જરૂરી છે.

મૂળ ગ્રંથોના લેખકો અને પ્રકાશકોની વિગતો ગ્રંથસૂચિમાં છે. તેમના ગ્રંથો માટે આપેલી કડીઓ પરથી મૂળ વાંચી શકાય છે. ગુજરાતી અનુવાદ અને સંપાદકીય કાર્ય માટેના મોડેલોની વિગતો [આવૃત્તિના પરિચય](../../README.md)માં છે. આ સૂચિની ગોઠવણી અને આ માર્ગદર્શિકાનું ગુજરાતી લખાણ OpenAI Codex — GPT-6 Astra (Ultra effort) દ્વારા તૈયાર થયાં છે.
