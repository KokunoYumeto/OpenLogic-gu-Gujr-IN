\olpart{ref}{સંદર્ભસામગ્રી}

\begin{editorial}
  આ ભાગમાં મૂળાક્ષરો, સંકેતો, વ્યાખ્યાઓ,
  નિયમો વગેરેની વિવિધ યાદીઓ એકત્ર કરી છે,
  જેથી પાઠ્યપુસ્તકમાં તેમને પરિશિષ્ટ
  તરીકે સામેલ કરી શકાય.
\end{editorial}
