\olpart{fol}{પ્રથમ-ક્રમ તર્કશાસ્ત્ર}

\begin{editorial}
  આ ભાગમાં પ્રથમ-ક્રમ તર્કશાસ્ત્રના અધિસિદ્ધાંતને પૂર્ણતા સુધી આવરી
  લેવાયો છે. હાલ તે વિધાનાત્મક તર્કશાસ્ત્રની અલગ રજૂઆત પર આધાર રાખતો
  નથી; બધું અહીં સાબિત કરવામાં આવે છે.
\end{editorial}
